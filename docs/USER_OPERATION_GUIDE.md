## 1. نظرة عامة وتسلسل الرحلة

تطبيق "صحيفتي" هو تطبيق لتتبّع حفظ وفهم القرآن الكريم. المستخدم المسجّل الذي يملك رخصة فعّالة يستطيع:
- تصفّح المصحف كاملاً (604 صفحات) مع تلوين الآيات حسب مستوى الحفظ وتسطير الفهم.
- تقييم كل آية (حفظًا وفهمًا) وإضافة تعليقات.
- رؤية صحيفته كرسم بياني (دائري وعمودي) لنسبة ما حافظه وفهمه.
- التقييم السريع والمسار المدرسي.
- ربط حسابه بمعلّم مشرف، وتلقّي توصيات المعلم على آيات محددة.
- إدارة إدارة المواضيع (للباحث/المراجع/المُعتمِد).
- إدارة التراخيص ورموز الهدايا وحسابات الأطفال.

**تسلسل الرحلة النموذجي:**
1. تشغيل التطبيق → شاشة الانطلاق.
2. "لدي حساب مسبقًا" → تسجيل الدخول (أو "ابدأ مسيرتك الآن" كضيف للتقييم السريع).
3. إن لم يكن الحساب مؤكّدًا → شاشة تأكيد البريد.
4. بعد الدخول: إن لم تكن هناك رخصة → شاشة تفعيل الترخيص.
5. بعد الترخيص: إن وُجدت جلسة قراءة محفوظة → يفتح القارئ على آخر موضع؛ وإلا → شاشة "صحيفتي" (`/me`).
6. من القائمة الجانبية (Drawer) يصل المستخدم لكل الشاشات الأخرى.

## 2. تشغيل التطبيق والانطلاق

**الشاشة:** شاشة الانطلاق (Onboarding Launch) — المسار: `OnboardingLaunchScreen.routeName`.

**ما يراه المستخدم:**
- شعار متحرك يتوسط الشاشة ثم تنزلق بطاقة محتوى.
- العنوان: "هل تعرف كم تحفظ من القرآن الكريم اليوم؟".
- النص: "إن كنت ترغب في حفظ سور أو أجزاء من القرآن الكريم، أو حتى تثبيت حفظك للسور التي تحفظها، فهذا التطبيق لك."

**الأزرار:**
| الزر | الإجراء |
|---|---|
| **"ابدأ مسيرتك الآن"** | يدخل كضيف إلى التقييم السريع (`/quick-assessment`). لا يتطلب تسجيل دخول. |
| **"لدي حساب مسبقًا"** | يفتح شاشة تسجيل الدخول (`/login`). |

**المتطلبات:** لا شيء — هذه نقطة الدخول.

## 3. تسجيل الدخول

**الشاشة:** تسجيل الدخول — المسار: `/login`.
**الملف:** `lib/screens/authentication_screens/login_screen.dart`.

**الخطوات:**
1. أدخل البريد الإلكتروني في حقل "البريد الإلكتروني".
2. أدخل كلمة المرور في حقل "كلمة المرور".
3. (اختياري) اضغط "تذكرني" (أيقونة علامة) لحفظ البريد للمرة القادمة.
4. اضغط **"تسجيل الدخول"**.
   - التحقق: حقول فارغة → خطأ "جميع الحقول مطلوبة"؛ بريد غير صالح → "بريد إلكتروني غير صالح".
   - إن لم يكن الحساب مؤكّدًا (خطأ `ACCOUNT_NOT_VERIFIED`) → ينتقل إلى `/verification-pending` مع البريد.
   - بيانات غير صحيحة → رسالة "بيانات الدخول غير صحيحة".
   - عند النجاح → ينفّذ `navigateAfterSuccessfulLogin` (الترخيص ثم الصفحة الرئيسية).
5. اضغط **"نسيت كلمة المرور"** → يفتح شاشة الاستعادة مع البريد المُدخَل.
6. اضغط **"إنشاء حساب"** (في التذييل) → يفتح شاشة التسجيل.

**الدخول الاجتماعي (Google/Apple/Facebook/Huawei):** يظهر زر لكل مزوّد مُهيّأ. اضغطه لإتمام الدخول عبر المزوّد. قد تظهر بعد ذلك شاشة "إكمال التسجيل الاجتماعي" لطلب اسم المستخدم والدولة والجنس.

## 4. إنشاء حساب

**الشاشة:** إنشاء حساب.
**الملف:** `lib/screens/authentication_screens/sign_up_screen.dart`.

**الخطوات:**
1. أدخل البريد الإلكتروني.
2. أدخل كلمة المرور (≥8 أحرف، تحوي كبير وصغير ورقم ورمز).
3. أدخل تأكيد كلمة المرور (مطابق).
4. اضغط **"إنشاء حساب"**.
   - التحقق: فارغ → "جميع الحقول مطلوبة"؛ بريد غير صالح → "بريد إلكتروني غير صالح"؛ عدم تطابق → "كلمتا المرور غير متطابقتين"؛ بريد مستخدم → "البريد مستخدم بالفعل".
   - يُشتق اسم المستخدم تلقائيًا من البريد.
   - عند النجاح → يمسح الحقول وينتقل إلى `/verification-pending` مع البريد.
5. اضغط **"تسجيل الدخول"** (في التذييل) للعودة.

**ملاحظة:** تظهر شاشة "الموافقة على الخصوصية" (PrivacyConsentGate) قبل التسجيل.

## 5. تأكيد البريد الإلكتروني

### 5.1 في انتظار التأكيد
**المسار:** `/verification-pending`.

**ما يراه المستخدم:**
- "أُرسل إلى" + البريد مخفّى (مثل `m***@gmail.com`).
- ثلاث خطوات تعليمية (تحقّق من البريد / اضغط الرابط / عُد للتطبيق).
- زر **"إعادة إرسال"** مع عدّاد 60 ثانية (معطّل أثناء الانتظار).
- زر **"تغيير البريد الإلكتروني"** → يعود لشاشة التسجيل.
- زر **"العودة لتسجيل الدخول"**.

**الخطوات:**
1. افتح بريدك واضغط رابط التأكيد (يوجّه التطبيق إلى معالج التأكيد).
2. إن لم يصل البريد، انتظر 60 ثانية ثم اضغط "إعادة إرسال".
3. عند النجاح → شاشة "تأكيد ناجح" → إن وُجدت رخصة فعّالة ينتقل إلى `/welcome`، وإلا إلى `/license-activation`.

### 5.2 نتائج التأكيد
شاشة "نتائج التأكيد" لها ثلاث حالات:
- **ناجح:** زر متابعة → رخصة فعّالة؟ `/welcome` : `/license-activation`.
- **منتهي:** زر يُعيدك لانتظار التأكيد.
- **فاشل:** زر يُعيدك لتسجيل الدخول.

## 6. استعادة كلمة المرور

**الشاشة:** استعادة كلمة المرور — مسار `/forgot-password` و`/reset-password`.
**الملف:** `lib/screens/authentication_screens/forget_password_screen.dart`.

**المراحل:**
1. **طلب إعادة التعيين:** أدخل بريدك → اضغط زر الإرسال → رسالة "أُرسل بريد إعادة التعيين".
2. **استلام البريد:** افتح رابط إعادة التعيين (يفتح المرحلة التالية).
3. **إدخال كلمة جديدة:** أدخل كلمة المرور الجديدة + التأكيد → اضغط زر الإرسال.
   - التحقق: ≥8 أحرف، كبير وصغير ورقم ورمز، تطابق.
4. **النتيجة:** نجاح → رسالة نجاح + زر العودة لتسجيل الدخول؛ انتهت صلاحية الرمز → شاشة "طلب رابط جديد".

## 7. اختيار الحساب المحفوظ

**الشاشة:** اختيار الحساب — `SelectUserScreen`.

**الغرض:** اختيار حساب محفوظ سابقًا على الجهاز للدخول السريع دون إعادة كتابة البيانات.

**ما يراه المستخدم:**
- عنوان "اختيار الحساب" مع عدّاد الحسابات.
- بطاقة لكل حساب محفوظ تعرض: الاسم، البريد، وشارة حالة:
  - "الحالي" (أزرق) — المستخدم الحالي.
  - "دخول فوري" (أخضر) — جلسة فعّالة محفوظة.
  - "يتطلب تسجيل دخول" (برتقالي) — يحتاج إدخال كلمة مرور.
  - شارة "حساب فرعي" (أخضر) لحسابات الأطفال.
- زر "×" على كل بطاقة لإزالة الحساب من الجهاز.
- زر **"تسجيل الدخول يدويًا"** + زر **"إنشاء حساب جديد"**.

**الخطوات:**
1. اضغط بطاقة حساب → يُكمَل الدخول (إن كانت الجلسة فعّالة) أو تُفتح شاشة تسجيل الدخول مع البريد المُعبّأ.
2. اضغط "×" لإزالة حساب محفوظ.

## 8. تفعيل الترخيص

**المسار:** `/license-activation`.
**الملف:** `lib/screens/authentication_screens/license_activation_screen.dart`.

تظهر هذه الشاشة عند تسجيل الدخول دون رخصة فعّالة. تقدّم ثلاث طرق:

### 8.1 عبر الهدية (Gift)
- اضبط بطاقة "هدية" ثم اضغط زر التفعيل.
- يستدعي `activateGiftLicense()` دون إدخال. عند النجاح ينتقل للرئيسية.

### 8.2 عبر رمز ترويجي (Promo Code)
- أدخل الرمز في حقل "رمز ترويجي" ثم اضغط زر التفعيل.
- يستدعي `activatePromoLicense(code)`.

### 8.3 عبر الشراء (Purchase)
- اختر كمية من القائمة (20/100/1000/10000 رخصة) — تظهر الأسعار بالدولار.
- اضغط زر الشراء (حاليًا يُظهر إشعار "قيد التجهيز").
- بعد إتمام الشراء خارجيًا، اضغط زر **"تحديث"** لإعادة فحص حالة الترخيص.

**زر "تسجيل الخروج":** يخرج ويعود لتسجيل الدخول.

## 10. شاشة صحيفتي الرئيسية

**المسار:** `/me` (`UserOverviewScreen.routeName`).
**الملف:** `lib/screens/user_overview_screen/user_overview_screen.dart`.

**هذه هي الصفحة الرئيسية بعد تسجيل الدخول** (حسب `post_auth_navigation`).

**ما يراه المستخدم:**
- شريط تطبيق بعنوان "صحيفتي" وأيقونة قائمة.
- ترويسة لاصقة:
  - رسم دائري (Donut) لأقسام التقييم (متمكّن/مراجعة/سهل/صعب/غير مصنّف) مع النسبة والقسم المميَّز.
  - حبوب مدمجة لكل قسم: "التسمية NN%".
  - زر **"صحيفتي"** أخضر → يُكمِل القراءة من آخر موضع (أو يفتح الفاتحة إن لم توجد جلسة).
  - شارة **"تصفية"** (تصفية نشطة) → يفتح لوحة تصفية (أثلاث / مكية/مدنية).
  - شارتا **"فتح الكل"** و**"طي الكل"**.
- قائمة السور: لكل سورة بطاقة فيها:
  - اسم السورة (قابل للضغط) → يفتح منتقي الآيات ثم نافذة تقييم.
  - شريط تقدّم (نسبة الإتقان، أخضر).
  - ملخص: "متبقي X آية (Y%)" و"متمكن X آية (Y%)".
  - سهم توسيع/طي يكشف رسم آيات السورة (أعمدة لكل آية).

**الخطوات:**
1. يُحمَّل التقييم وبيانات المستخدم وكل الآيات عند الفتح.
2. شاهد الرسم الدائري للحصول على نظرة سريعة.
3. اضغط **"صحيفتي"** للعودة لآخر موضع قراءة.
4. اضغط **"تصفية"** لتصفية السور بالثلث أو النوع.
5. اضغط **"فتح الكل"/"طي الكل"** لتوسيع/طي كل البطاقات.
6. **اضغط اسم سورة** → اختر آيات → عيّن تقييمًا → يُحدَّث التقدّم.
7. اسحب للأسفل لتحديث كل البيانات.

## 12. تصفّح القرآن وتقييم الآيات

**المسار:** `/read` (`IndexPage.routeName`).
**الملف:** `lib/screens/quran_view/index_page.dart`.

**هذه هي شاشة القراءة والتقييم الأساسية.**

### 12.1 شريط التطبيق (RTL)
من اليسار لليمين:
1. **أيقونة القائمة** → تفتح القائمة الجانبية. (في وضع مشرف يعرض الطالب زر رجوع "العودة".)
2. **حبة السورة** (اسم السورة الحالية) → الضغط يفتح منتقي السور.
3. **أيقونة التصفية** (مع شارة عدد الفلاتر النشطة) → تفتح لوحة التصفية الموحّدة.
4. **أيقونة لوحة الألوان** → تشغيل/إطفاء ألوان الحفظ على الآيات.
5. **أيقونة التسطير** → تشغيل/إطفاء تسطير الفهم تحت الآيات.
6. **أيقونة اللمس** → تشغيل/إطفاء "وضع تحديد الآيات" (تحديد متعدد). في وضع المشرف يتحول لنص "اضغط على آية لإرسال توصية".
7. **أيقونة معلومات** (عند وجود تنبيه قراءة) → شرح القيد الحالي.

### 12.2 التصفّح
- جسم الصفحة فيه `PageView` يتنقل في صفحات المصحف (604 صفحة) بالسحب الأفقي.
- الشريط السفلي:
  - **حبة الجزء** "الجزء {n}" → الضغط يفتح منتقي الجزء.
  - **عنوان التقدّم** "{page} / 604" (قابل للضغط لفتح منتقي الصفحة) أو "Q{hizbQuarter}".
  - **سهمان** للانتقال للصفحة السابقة/التالية.

### 12.3 التصفية
لوحة التصفية الموحّدة تشمل:
- **مرشّحات النطاق** (تحدّد الصفحات القابلة للتنقّل):
  - **الأثلاث** (افتراضي) — تقسيم 30 جزءًا إلى 3 مجموعات.
  - **الأجزاء** — اختيار أجزاء 1–30.
  - **الأحزاب** — اختيار أحزاب 1–60.
  - **الموضوعات**.
- **مرشّحات العرض** (تُخفت الآيات غير المطابقة):
  - نوع الآية (مكية/مدنية/مختلف فيها).
  - الموضوعات.
  - المدرسة + المستوى.
  - تقييم حفظ محدّد (مثل: أرني الآيات المتمكنة فقط).
  - تقييم فهم محدّد.

عند تفعيل مرشّح نطاق: يُعاد بناء تسلسل الصفحات ليشمل فقط الصفحات التي فيها آية مطابقة، ويُقزَم التنقّل ضمن هذا النطاق. عند تفعيل مرشّح عرض: تُخفت الآيات غير المطابقة (رمادي).

### 12.4 تقييم آية واحدة (الحفظ والفهم)
1. اضغط آية (أو علامة نهايتها ۝).
2. تُفتح **نافذة التقييم** (AssessmentInputDialog):
   - العنوان: "تقييم حفظ وفهم" (أو "تقييم الحفظ"/"تقييم الفهم" حسب الأبعاد المتاحة).
   - قسم **الحفظ**: صف من رقائق (ChoiceChips)، واحدة لكل تقييم (متمكن/مراجعة/سهل/للحفظ/صعب)، ملوّنة بلون التقييم. الضغط على رقاقة محدّدة يلغيها.
   - قسم **الفهم**: رقائق مماثلة (نعم/لا).
   - ملخّص الموضوعات (إن وُجدت) كرقائق.
   - حقل **التعليق** (إن مُكِّن): "تعليق" متعدد الأسطر.
   - أزرار: معلومات، "إلغاء"، "حفظ" (معطّل حتى يُغيَّر حقل واحد).
3. عند الحفظ → يُرسَل التقييم → النجاح: رسالة "تم تقييم الآية بنجاح"؛ دون اتصال: "تم حفظ التقييم على الجهاز وسيتم مزامنته عند عودة الاتصال".
4. تُعاد الآية باللون/التسطير الجديدين فورًا.

### 12.5 التقييم الجماعي (وضع التحديد)
1. اضغط أيقونة اللمس في الشريط لتفعيل "وضع تحديد الآيات".
2. اضغط آيات لتحديدها (خلفية ملوّنة شفافة).
3. يظهر زر **"تطبيق على {count} آية محددة"** أسفل الصفحة.
4. اضغطه → نافذة التقييم الجماعي (بدون تعليق، مع ملخّص الموضوعات المشتركة) → اختر تقييم الحفظ/الفهم → حفظ → يُطبَّق على كل الآيات المحددة.

### 12.6 إظهار/إخفاء الألوان والتسطير
- أيقونة لوحة الألوان تتحكّم في تلوين الآيات حسب تقييم الحفظ (مع حساب التباين لتسهيل القراءة).
- أيقونة التسطير تتحكّم في تسطير الآيات التي عليها تقييم فهم إيجابي (نعم). لون التسطير = لون الحفظ للآية نفسها.

### 12.7 حفظ جلسة القراءة
- يُحفَظ الموضع (السورة، الجزء، الصفحة، نوع التصفية) تلقائيًا عند كل تغيير صفحة.
- عند إعادة فتح التطبيق: المستخدم المرخّص يُستأنف تلقائيًا من آخر موضع. (الضيف لا يُحفَظ موضع قراءته.)

### 12.8 شاشة التقييم غير المتاحة
- **الضيف:** لا يمكنه فتح نافذة التقييم. الضغط على آية يعرض تنبيهًا: "هذه الميزة متاحة بعد تسجيل الدخول" مع زرَّي "الإكمال كضيف"/"تسجيل الدخول".
- **مسجّل دون رخصة:** "قم بتفعيل الرخصة للوصول لميزات التقييم المتقدمة."

## 14. شاشة الأسئلة/المسارات

5. **شاشة الإكمال:** عرض مقاييس (وحدات مكتملة، مستويات مكتملة، آخر مستوى، وحدات متبقية) + زر **"متابعة"** للمستخدم المسجّل يفتح شاشة الرسم البياني مرشّحة بمدرسة/مستوى، أو زر **"إنشاء حساب"/"تسجيل الدخول"** للضيف.

## 16. الإشراف التربوي

**المسار:** القائمة الجانبية → "لوحة الإشراف" (يظهر فقط عند وجود طلبات/روابط/مشرف معروض).
**الملفات:** `lib/screens/supervision_screen/`، `lib/screens/profile_screen/add_supervisor_screen.dart`.

### 16.1 الطالب: ربط حسابه بمعلم
1. افتح الملف الشخصي → اضغط زر **"+"** الأرجواني → تفتح شاشة "مسح رمز المعلم".
2. وجّه الكاميرا نحو رمز QR للمعلم، أو اضغط **"اختيار صورة من المعرض"** لالتقاط رمز من صورة.
3. الأدوات: زر الفلاش، زر تبديل الكاميرا.
4. بعد قراءة الرمز → تظهر لوحة معاينة "إضافة معلم مشرف" تعرض هوية المعلم وتحذيرات (حسابك الخاص / إشراف فعّال / طلب بانتظار).
5. اضغط **"إرسال الطلب"** → يُرسَل الطلب.
6. النتيجة: "تمّ إرسال الطلب" أو "الطلب في انتظار الرد" أو "الإشراف فعّال".

### 16.2 المعلم: مشاركة رمزه
1. افتح الملف الشخصي → بطاقة "رمز حسابك".
2. اضغط **"مشاركة"** أو **"حفظ كصورة"**.

### 16.3 المعلم: لوحة الإشراف
**المسار:** `/supervision-dashboard` (`IncomingRequestsScreen`).

**ما يراه:**
- **بطاقة الحدود:** "طلابي الفعّالون {teacherActiveCount}/25" و"معلّمون يشرفون عليّ {studentActiveCount}/5".
- **قسم "طلبات الإشراف الواردة":** لكل طلب: اسم الطالب + بريده + ثلاثة أزرار:
  - **"قبول"** → يقبل الطلب. إن بلغ 25/25 تظهر لوحة "اختر أحد طلابك الحاليين لإزالته" ثم "إزالة وقبول". إن بلغ الطالب 5/5 تظهر رسالة "الطالب وصل إلى الحد الأقصى للمشرفين".
  - **"رفض"** → نافذة تأكيد "لن يستطيع الطالب إرسال طلب جديد لمدة 24 ساعة" → "رفض".
  - **"مراجعة لمرّة واحدة"** → نافذة تأكيد "ستفتح جلسة عابرة..." → "فتح الجلسة". يمكن إغلاقها لاحقًا.
- **قسم "طلابي الفعّالون":** يعرض روابط الإشراف الفعّالة. لكل طالب ملخص حفظ مباشر + أيقونة بحث تفتح **شاشة نظرة الطالب** (مثل صحيفة المستخدم لكن للطالب) فيها زر "صحفة [الطالب]" يفتح القارئ في وضع العرض المُفوَّض للطالب.
- **قسم "معلّمون يشرفون عليّ":** روابط الإشراف التي فيها الطالب.

**الحدود:** المعلم حتى 25 طالبًا، الطالب حتى 5 معلمين. الرفض يمنع الطلب لمدة 24 ساعة. جلسة المراجعة لمرّة واحدة لا يمكن إعادة فتحها بعد إغلاقها.

## 18. إدارة إدارة المواضيع

**المسار:** القائمة الجانبية → "ادارة البطاقات" (يظهر للأدوار 1–5).
**الملفات:** `lib/screens/cards_screen/cards_list_screen.dart`, `card_detail_screen.dart`.

**عنوان القائمة حسب الدور:**
| الدور | العنوان |
|---|---|
| طالب/مدير/أخرى | "إدارة المواضيع" |
| باحث (3) | "بطاقاتي البحثية" |
| مراجِع (4) | "قائمة المراجعة" |
| مُعتمِد (5) | "قائمة القبول" |

### 18.1 قائمة البطاقات
- شريط بحث "بحث في البطاقات...".
- رقائق تصفية الحالة (للأدوار ≥2): الكل / للمراجعة / قبول جزئي / قبول أولي / مقبولة / مرفوضة.
- كل بطاقة: نقطة حالة ملوّنة، اسم الموضوع، نطاق المحتوى (مثل "البقرة 1-5")، شارة حالة.
- ترقّم تلقائي عند التمرير للأسفل + سحب للتحديث.

### 18.2 تفاصيل البطاقة
- العنوان "تفاصيل البطاقة".
- بطاقة معلومات: الموضوع، النطاق، الآيات (بنص المصحف)، الحالة، تاريخ الإنشاء.
- قسم "الباحثون".
- قسم "تعليقات المراجعة".
- **إدخال التعليق** (للأدوار ≥3): حقل "أضف تعليقًا..." + زر إرسال. نجاح: "تمت إضافة التعليق".
- **إجراءات سير العمل** (حسب الدور والحالة):

| الدور | الحالة الحالية | الحالات المتاحة |
|---|---|---|
| مراجِع (4) | للمراجعة | قبول جزئي، قبول أولي، مرفوضة |
| مراجِع (4) | قبول جزئي | قبول أولي، مرفوضة |
| مُعتمِد (5) | قبول أولي | مقبولة، مرفوضة |
| مدير (2) | أي | كل الحالات |

- **الرفض:** يضغط "مرفوضة" → تظهر بطاقة "سبب الرفض" بحقل إدخال + "تأكيد الرفض".
- بعد التحديث: رسالة "تم تحديث الحالة" أو "فشل تحديث الحالة".

**سير حالة البطاقة:**
```
للمراجعة → (مراجِع) → قبول جزئي → (مراجِع) → قبول أولي → (مُعتمِد) → مقبولة أو مرفوضة
```
مرفوضة ومقبولة حالات نهائية. المدير يمكنه تجاوز أي حالة.

## 24. العمل دون اتصال

التطبيق مصمّم للعمل دون اتصال بشكل واسع:

- **نصوص الآيات:** كل 6236 آية مُضمَّنة في `assets/json/data.json`، متاحة دائمًا.
- **التقييمات:** تُحفَظ في ذاكرة محلية (SharedPreferences) وتُعرض فورًا.
- **التقييم دون اتصال:** عند تقييم آية دون اتصال، تُطبَّق محليًا فورًا ويُظهَر الرسالة "تم حفظ التقييم على الجهاز وسيتم مزامنته عند عودة الاتصال". تُوضَع في قائمة انتظار وتُزامَن تلقائيًا عند عودة الاتصال.
- **شارة المزامنة المعلّقة:** تظهر أعلى جسم القارئ تعرض عدد التقييمات المنتظرة.
- **الرسم البياني:** يُبنى محليًا من البيانات المخزّنة، لذا يعمل دون اتصال.
- **الإشراف:** عمليات الكتابة (قبول/رفض/مسح) تتطلب اتصالاً (تُطلق خطأ `offline_write_not_supported`). عمليات القراءة تستخدم البيانات المخزّنة.
- **البطاقات:** القراءة تدعم ذاكرة محلية، الكتابة (تحديث حالة/تعليق) تتطلب اتصالاً.

## 25. الأدوار والصلاحيات

| userRoleId | الدور | الوصول |
|---|---|---|
| 0 | ضيف | تصفّح القرآن فقط (بدون تقييم/ألوان/تسطير). التقييم السريع متاح لكن لا يُحفَظ. |
| 1 | طالب (student) | كل ميزات المستخدم المرخّص. يرى إدارة المواضيع المقبولة فقط. |
| 2 | مدير (admin) | كل الصلاحيات + إدارة المستخدمين + تجاوز أي حالة بطاقة. |
| 3 | باحث (researcher) | يرى بطاقاته البحثية + إنشاء/تعديل بطاقات. |
| 4 | مراجِع (reviewer) | يرى قائمة المراجعة + قبول جزئي/أولي/رفض + تعليقات. |
| 5 | مُعتمِد (admitter) | يرى قائمة القبول + قبول نهائي/رفض. |

**حراس الطرق (Route Gates):**
- `AuthenticatedRouteGate`: يتطلب تسجيل دخول + رخصة فعّالة. إن لم توجد رخصة → يُعيد توجيه إلى `/license-activation`.
- `GuestAwareRouteGate`: ثلاث طبقات (ضيف/مسجّل/مرخّص) مع قيود الضيف (`canSaveProgress=false`, `canOpenAssessmentDialog=false`, `canUseAdvancedFilters=false`, `canEnterSelectionMode=false`).
